# First application: optional CV, uninterrupted progress

Correction — 16 November 2026. This overrides the CV gate in brief 09 and any earlier prototype description. A CV prompt must never block continued discovery, preparation or application handoff.

The first-search goal is an application submitted by the candidate, or a useful application handoff saved for their own submission. Uploading a CV and completing a profile are optional ways to improve that journey, not its completion criteria.

## Three preparation choices

1. Add an existing CV, review it and use it for better matching and application preparation.
2. Create a CV through guided questions covering introduction/contact, target work, experience or volunteering, education, achievements, projects, skills and evidence. Generate a structured rich-text draft from the answers; enable WYSIWYG edits and exact-version review/approval before use.
3. Continue without a CV. Explain that filter fit is not personal fit, experience/eligibility remain unverified, and supported tailored documents cannot be created without enough career information. Record scoped risk acknowledgement, then continue to the opportunity, application instructions, available information and submission checklist.

An employer may require a CV. Communicate that employer requirement without pretending JobPunter can bypass it. Offer guided creation or upload while preserving the selected opportunity and preparation progress. Never invent career details, produce an empty document labelled ready, or call an unverified opportunity a strong Punt.

Further global searches remain available whether the CV prompt is followed or ignored. Pool search remains distinct from external acquisition. Skipping CV upload is not consent to fabricate evidence or silently approve generated content.

## Handoff and tracking contract

Store the selected opportunity ID, assessed/unverified fit state, explicit missing documents, verified application destination, available artifact versions and risk acknowledgement with timestamp and scope. Handoff-ready is separate from package-complete and submitted. A checklist-only handoff must clearly say that no CV or cover letter was prepared.

Record handoff completion independently of manual-submission confirmation. Never move an opportunity to Applied because a portal link was opened or handoff saved. Submission requires candidate confirmation; JobPunter sends no application. Later supplied CVs can enrich the same opportunity without creating a duplicate or erasing previous decisions.

## Guided creation backend support

Persist resumable questionnaire drafts and answers with source attribution. Adapt questions to the candidate’s discipline and career stage; no employment experience is a supported case. Allow unknown/not applicable answers, custom entries and multiple education/experience/project records. Do not ask for unsupported numerical achievements.

The generation request binds to confirmed answers and evidence, using brief 09’s structured rich-document contract. Track missing information, grounding and source versions. A questionnaire-generated starter CV is distinct from the later comprehensive Master CV generated from the full Master Career Profile. Reuse answers as reviewable profile drafts rather than making the candidate type them again or silently approving their full profile.

Acceptance checks: skip upload and repeat a global search; select any collected opportunity; acknowledge limits and save a handoff; confirm manual submission separately; create a CV from answers; edit/approve the generated version; return to the selected opportunity; preserve state through all three choices. Verify that unsupported fit claims and document-ready states never appear on the no-CV path.

The preview demonstrates local guided drafting and a clearly labelled sample handoff. It does not perform live AI generation, open a real employer portal or create downloadable application files.
