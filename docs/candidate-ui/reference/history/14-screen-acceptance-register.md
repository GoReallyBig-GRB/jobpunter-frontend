# Screen-by-screen design acceptance register

18 November update: the current preview retains the registered views and adds two package-flow screens, for 126 total. `context-cover-choice` makes the optional-letter decision after CV selection; `context-package-review` displays the actual selected documents in paper format, retains editing context, approves exact revisions and leads to download/copy and the external channel on the same screen. Both follow the five-question rule and have targeted first-time/returning-user and mobile checks. The older `context-handoff` is a retained reference; the active flow uses the final package screen.

17 November 2026. Covers all 124 available views. Each row specifies what the screen must answer under the five-question rule. Responsive rendering was checked at 320, 390 and 736 pixels in one populated candidate state; this does not certify every permission, failure or empty state.

They remain in the review picker to preserve prior work, not as separate routes to ship.
