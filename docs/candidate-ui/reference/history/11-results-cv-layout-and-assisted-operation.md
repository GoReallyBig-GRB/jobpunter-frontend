# Results, document layout and ongoing assistance

Updated 16 November 2026. This supersedes conflicting earlier search-result, no-CV handoff and post-variant navigation details.

## First search delivers a Job Pool

Show **Your search results**, the applied filter summary and the actual collected opportunities. These are filter-qualified jobs, not Punts. Do not lead with another search form or a request to run another global search. Retain global discovery as a separate optional Home/Discovery action, without a CV gate.

The primary refinement is **Upload your CV**; the alternative is **Create a CV from scratch**. Questionnaire answers are used to generate an editable professional rich-document draft. Both routes converge on review and approval of the CV, then fit analysis of each already collected opportunity. This is an assessment run, not another acquisition run. Store result-set ID, every opportunity/JD revision, approved CV version, evaluation state and reason. Punts are only the strongest supported matches. Return assessed/non-match/uncertain states and explanations without manufacturing candidate facts or claiming universal fit.

Use this CV as the retained source for background Master Career Profile drafting or updating and Career Pathway identification, unless the candidate replaces it. The approval action explicitly authorizes those draft preparations. Preserve provenance and conflicts; no background job may approve the profile, select pathways or approve a document on the candidate’s behalf. Drafts surface through Review and Home; application work need not wait for full setup.

Without an uploaded or created CV, show employer requirements and next steps only. Do not generate a tailored CV, evidence-backed cover letter, package-ready event or completed materials handoff. The no-CV route is informational. Employer submission remains candidate-owned. A real Punt proceeds through supported document generation, review, package approval and handoff; record a preparing/ready opportunity in its pipeline without conflating handoff with Applied. Applied requires actual manual-submission confirmation.

## One professional document, two views

Every CV has canonical document settings: paper size (A4 default, optional supported Letter), portrait orientation, margins, font metrics, section styles, paragraph spacing, headers/footers and page-break rules. Mobile reading is a presentation of the same document, not a mobile-format CV for submission.

Offer **Mobile reading** and **A4 document** on CV review. Standard document view scales the paper to the device and preserves paper proportions, typography and pagination. Production additionally needs zoom/pan and accessible page navigation. Editing must retain the same document schema and page settings across both views. Export DOCX/PDF from the approved version and same layout contract; never treat an arbitrary responsive screen as the export source.

The prototype previews A4 proportions with block-level pagination. It is not a print-fidelity export engine: long blocks can require pagination refinement. Production must test split paragraphs/lists, widows/orphans, multi-page experience, links, font substitution, page numbers and selectable-text exports. Compare paper preview with the actual exported PDF/DOCX before claiming layout fidelity.

## After CV Variants are approved

Approving the last required variant ends document setup and opens **Let JobPunter keep things moving**. If other selected variants still need review, return to that list with remaining work visible. Do not loop through drafting or source-selection screens after acceptance.

The finish-setup screen has two clear tasks: set an approved discovery schedule using completed career context; optionally authorize Gmail alert access when genuinely supported. Preferences and notifications are secondary configuration. Keep unavailable Gmail honest and allow pasted alerts and other approved sources. Gmail is optional, not a prerequisite for scheduled discovery.

Home becomes the operational hub: recommended Punts, approval requests, package handoffs awaiting submission, pipeline developments, dated activity and discovery/source health. Career holds editable approved foundations and version history. Review holds genuine decisions; Punts holds recommended opportunities; Pipeline holds preparing, ready and submitted opportunity states without treating them as equivalent.

Recurring discovery, alert processing, deduplication, fit assessment and preparation operate within explicitly approved scope. Candidate work is primarily reviewing opportunities/documents, submitting applications, confirming proposed pipeline updates and responding to exceptions. Manual global search stays optional. Source or context changes cannot silently broaden consent; new generated versions always need approval.

## Backend acceptance checks

- CV-based fit analysis does not issue a fresh external search; every initial result gets an assessment or an explicit failure state.
- Both upload and questionnaire generation converge on the same versioned source contract and background profile-draft workflow.
- Replacement CVs re-evaluate dependent drafts and matches, preserve prior evidence and expose conflicts.
- No ungrounded Punt, application document or package-ready status exists on the no-CV route.
- Final variant approval routes to operational setup once; changed variants reopen only relevant review work.
- Scheduled acquisition and Gmail ingestion remain distinct permissions, with observed health and honest failure/partial states.
- Paper preview and exported documents retain the same canonical page settings and approved content.
